## Featured Projects

### 1. Universal Log Pre-Processing Framework (ULPF)

A modular cybersecurity data pipeline designed to ingest, parse, normalize, and process log events.

- Uses **Vector** for log ingestion, parsing, and OCSF schema normalization.
- Includes a **Rust-based worker** to transform normalized JSON events into compressed Apache Parquet files.
- Integrates a Streamlit dashboard for pipeline monitoring and schema testing.
- Uses Docker Compose for multi-container deployment.

**Technologies:** Rust · Vector · OCSF · Apache Parquet · Docker Compose · Streamlit · ClickHouse

### 2. Distributed Key-Value Store

A Rust-based distributed storage engine under development, focused on persistence and distributed coordination.

- Implementing persistent storage with a **write-ahead log (WAL)** and snapshot-based state management.
- Developing REST and TCP interfaces for client interaction.
- Exploring distributed coordination using **Raft**.

**Technologies:** Rust · Tokio · Raft · Axum · gRPC · Protocol Buffers

### 3. Multithreaded Key-Value Store

A concurrent key-value storage engine with persistent storage and client-facing interfaces.

- Implemented persistent storage with custom binary serialization.
- Built concurrent read/write operations using asynchronous programming.
- Used `RwLock` and `Mutex` for shared-state synchronization.
- Designed TCP and HTTP interfaces.

**Technologies:** Rust · Tokio · Concurrency · File I/O · Networking

### 4. PDFChatBot

An AI-powered document assistant that answers questions about PDF documents.

- Uses semantic search with an LLM fallback to answer document-related questions.
- Implements JWT authentication and vector storage with Qdrant.
- Exposes functionality through a FastAPI REST API.
- Containerized with Docker.

**Technologies:** Python · FastAPI · LLMs · Semantic Search · Qdrant · Docker
